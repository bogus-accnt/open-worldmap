open-worldmap

An embeddable JavaScript widget that organizes arbitrary JSON data by country on an interactive world map. Pick an example below.

  • Full demo (ES modules) Dataset switching, record editor panel, search, region filter, records table.
  • Radio stations by country Records are arrays of stations; the map is shaded by station counts and clicking a country filters the table.
  • Bundled build (no modules) Loads dist/worldmap.min.js with a plain <script> tag via window.WorldMap.
